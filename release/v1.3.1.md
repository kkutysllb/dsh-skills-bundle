## 修补（5 项）

1. **executing-plans 描述与内容脱节修复**：描述仍写「separate session」，
   而 v1.3.0 已重写为同会话内联执行 + 进度账本 + 终末评审——描述改为
   「executing a written implementation plan end to end」，同步 manifest core 批；
2. **plans/ 命名规则统一**：planning-with-files 新增命名优先级表（活计划
   `plans/<task-slug>.md`／设计文档 `YYYY-MM-DD-<topic>-design.md`／实现计划
   `YYYY-MM-DD-<feature-name>.md`／执行账本 `YYYY-MM-DD-<slug>-progress.md`），
   并规定已有设计/实现计划时原位更新、不另建第二个文件；
3. **frontend 两技能边界收敛**：frontend-engineering（跨框架集成：状态、
   数据获取、表单、路由协作）与 react-nextjs（RSC/App Router 特有机制）
   描述互相排除，消除路由竞争；同步 manifest core 批；
4. **smoke 新增 Agent Skills 规范断言**：注册面全部技能（core + optional
   直接目录）校验 name ≤64/小写数字连字符、description 非空且 ≤1024、
   frontmatter 存在；并断言扫描数与 manifest 计数一致。当前最长描述
   952 字符（foundry），断言可提前拦截其月度同步漂移；
5. **webapp-testing 补浏览器 MCP 段**：环境有浏览器自动化 MCP 时优先直驱
   探索，脚本保留给可复现验证（回归/CI/精确断言）。

## 新增技能（optional，37 → 40）

1. **dsh-plugin-authoring**（187 行 SKILL.md + 4 个 references）——
   dsh/QiLin/KCoder 宿主插件创作全链路：host cordis 插件形态、client 侧
   HAND-MAINTAINED ModuleLoader 自注册、双通道 bundle patch、fenced API 与
   Host 回环边界、slots/locale、状态持久化、profile 安装与 pnpm 供应链策略
   坑（minimumReleaseAge 只认裸包名）、smoke/selftest 契约、镜像同步纪律、
   发版流水线。**上游无等价技能**，为本生态知识沉淀；
2. **mcp-server-authoring**（164 行）——MCP server 设计方法论：该不该做
   server 的判据、工具面（少而正交、description 即 prompt、JSON Schema
   约束）、返回与错误契约（错误分类/幂等键/分页）、stdio vs Streamable
   HTTP、鉴权边界、安全（路径穿越/命令注入/SSRF/密钥）、Inspector + 契约
   测试、可观测与版本演进；15 条交付清单。注意：Anthropic 的 mcp-builder
   所在仓库无许可证，本技能为自写方法论，未拷贝原文；
3. **agent-system-design**（122 行）——LLM/agent 系统工程：上下文预算账本
   （80% 告警/60% 压缩）、能力面设计（15–25 工具路由退化阈值）、结构化
   输出四层校验、eval 驱动迭代（30–100 条真实 trace 黄金集、合并前回归门）、
   成本/延迟上限、失败语义表、间接注入防护、trace 可观测；14 条交付清单。
