# dsh-skills-bundle 1.0.2

## 变更

- 麒麟（QiLin）双通道适配：package.json manifest 同时声明 `qilin.bundle.patch` 与 `dsh.bundle.patch`，指向同一份 `cordis.patch.yml`，行为完全一致。QiLin（dsh 0.1.6-alpha.2 合并后）的插件管理器只认原生键 `qilin.bundle.patch`（缺失会报「没有声明组合包」）；DSH 宿主仍读 `dsh.*`，零代码改动。
- npm 包 `files` 白名单补入 README.md：QiLin 安装文档随包分发。
- README 新增「麒麟（QiLin）引擎安装」章节：
  - 两种安装方式：npm registry（`qilin plugin --profile qilin add dsh-skills-bundle`）与 GitHub 直装；
  - 注意事项——必须经 `qilin plugin add` 装进 profile 私有 `node_modules`（共享 `~/.qilin/profiles/node_modules` 在 alpha.2 合并后划为安装保留区，放那里激活直接 `failed to import`）；运行需带 dsh 兼容层的 QiLin 3.0.0+，插件管理（设置页展示/启停）需 3.0.2+；dsh alpha.2 起依赖解析默认运行时模式（PR #4471），本仓 host 侧零 npm 运行时依赖，天然兼容。

## 安装

DSH：

```bash
dsh plugin --profile web add dsh-skills-bundle
```

麒麟（QiLin 3.0.2+）：

```bash
qilin plugin --profile qilin add dsh-skills-bundle
# 或 GitHub 直装
qilin plugin --profile qilin add github:kkutysllb/dsh-skills-bundle
```

KCoder 桌面版随版本内置分发，无需安装。
