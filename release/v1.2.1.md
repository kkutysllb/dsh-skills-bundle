## 背景

2026-10-25 技能资产审计发现：6 个技能的 SKILL.md 指向不存在的伴随文件，
而 smoke 22/22 全绿——旧引用检查只匹配 `skills/<name>/<file>` 全路径形态，
`./x.md`、`@x.md`、`scripts/…` 等相对引用全部不可见（与 2026-10-05 同步
排除规则事故同构：静态检查双侧一致地一起错，直到真机执行才炸）。

## 变更

断链修复（补齐载荷，而非删引用）：

- `skills/webapp-testing/`：新增 `scripts/with_server.py`（多服务器生命周期
  管理，stdlib 实现，CLI 与文档一致）与 `examples/` 三个示例脚本；
- `skills/test-driven-development/`：新增 `testing-anti-patterns.md`
  （五类反模式 + 变异自检收尾）；
- `skills/subagent-driven-development/`：新增三个派单模板
  `implementer-prompt.md` / `spec-reviewer-prompt.md` /
  `code-quality-reviewer-prompt.md`（含 DONE/DONE_WITH_CONCERNS/NEEDS_CONTEXT/
  BLOCKED 状态协议与两阶段评审裁决格式；措辞引擎中立）；
- `skills/requesting-code-review/`：新增 `code-reviewer.md` 评审模板
  （四占位符与正文一致，Critical/Important/Minor 分级输出）；
- `skills/optional/internal-comms/`：新增 `examples/` 四个指南
  （3p-updates / company-newsletter / faq-answers / general-comms）。

引用与文本修正：

- `skills/optional/project-delivery-workflow/`：三个不存在的技能名改为
  在库技能（`playwright-verification`→并入 webapp-testing；
  `code-review`→`requesting-code-review`；`security-review` 删除，
  security-hardening 已在 Design 阶段激活）；
- `skills/optional/internal-comms/` description 去除 "Claude should use
  this skill" 残留（manifest.optional 已重新生成）；
- `skills/subagent-driven-development/`：Integration 空标题补上实际内容；
- `skills/webapp-testing/`：拼写 abslutely → absolutely。

工具链强化：

- `scripts/smoke-plugin.mjs` 新增**相对引用存在性检查**：递归覆盖全部
  SKILL.md（含 optional 嵌套子技能），校验 `./`、`../`、`@`、反引号
  `scripts|examples|references|assets|templates/` 前缀与 `<技能名>/` 前缀
  六类引用形态；文档语法样例走显式豁免清单（当前 1 条：slidev 的
  `src: ./other.md` 示例）。本次运行即校验 30 条相对引用。
