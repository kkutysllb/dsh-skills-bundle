## 背景

2026-10-25 技能资产审计（67 技能逐字审读 + 上游生态联网调研）结论：
本包方法论批是上游 obra/superpowers 约 v4 时代（2025-12）的快照，上游已
演进至 v7.0.1（2026-10-21），其间有一批经实测验证的实质改进；microsoft-foundry
为官方 2026-09 中之前的旧快照（官方已是 1.2.31，新增 toolbox/voice/harness
等 77 个文件）；另有 21 个技能存在宿主工具名/内部代号/品牌残留。

## 变更

### 流程方法论重写（对齐上游 MIT，引擎中立化改写）

- **brainstorming**（v7.0/v6.3）：先读项目再提问、理解回放纠错、
  spike/小改/项目三级工作量分级、2-3 方案先行+推荐、builder check
  （新增 builder-check-prompt.md）、HARD-GATE 保留、visual companion 即时提供；
- **writing-plans**（v6.4.2）：计划记录「决策」而非「代码转写」；
  计划头新增 Spec / Global Constraints / Review Focus / Interfaces 块；
  自审含长度比例检查；
- **executing-plans**（v6.4.1）：整份计划一次跑完 + 终末一次全分支评审；
  内联 vs 子代理双路线成本对比；rulings-not-stalls；抗 compaction 进度账本
  `plans/*-progress.md`；
- **subagent-driven-development**（v6.2–v7.0）：计划作用域工作区
  `.agent/sdd/<plan-basename>/` + 账本身份 + 终审后删除；single
  task-reviewer（规格+质量双 verdict，替代 v4 两阶段双模板）+ 范围化
  re-review + **5 轮熔断**；no-subagents 契约；batching；SKILL.md 瘦身至
  13.2KB，深材料拆 references/ 七件按步读盘（抗 2 万字符截断教训）；
- **test-driven-development**（v6.2）：testing-anti-patterns.md 重构为
  **writing-good-tests.md**（六条 GOOD 先行规则 + 可证伪性纪律：
  string-presence / change-detector 陷阱、独立推导期望、mutation check）；
  「项目全套件才算绿」；
- **requesting-code-review**（v6.4.1）：多提交 BASE_SHA 改用
  `git merge-base origin/main HEAD`（防 main 前移幻影删除）；
- **finishing-a-development-branch**（v6.2/v6.3）：收尾菜单不再提供
  「丢弃工作」；worktree remove 因未提交改动拒绝时点名文件询问，绝不 `--force`。
