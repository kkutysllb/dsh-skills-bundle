# dsh-skills-bundle 1.1.0

## 变更

- **新增「可选技能」批（optional，40 项）**：`skills/optional/` 长尾技能（xlsx、pptx、docx、pdf、deployment、database、web-design-guidelines 等）随包分发但**默认不注册**——引擎不知道它们存在，零目录税。核心批（31 项）语义不变，激活即注册。
- **设置页新增「可选技能」分区**（`settings.section` 插槽，QiLin/DSH 设置壳左栏直达）：开关卡片列出全部可选技能，打开即对该引擎的所有会话生效（模型按 description 匹配加载，或 `/技能名` 显式调用），关闭即注销。开关状态由宿主插件就地重注册实现，**即时生效、无需重启**。
- **宿主插件挂 fenced JSON API**（`/kcoder-skills/api`，Host 回环信任边界，非回环 Host 403）：`GET catalog` 出两批清单与启用态，`POST set-enabled` 改启用集。DSH/QiLin 的 settings RPC 不服务第三方命名空间（dsh-coding-sidebar 同款结论），故读写走插件自有路由。
- **启用集持久化**：`$QILIN_HOME/kcoder-skills.json`（0600），引擎重启按文件恢复；web 端与桌面端共享同一引擎，状态一致。未知技能名一律过滤（清单先行校验），坏请求 400。
- **元数据流水线**：`pnpm gen:manifest` 扫 `skills/optional/*/SKILL.md` frontmatter 生成 `manifest.optional`（core 批保持人工精选，脚本从不改写）；client 侧无法读盘，清单由 manifest 单一事实源对账。
- **client 交付物**（`./client` → `client.js`）：dsh-animations 同款 HAND-MAINTAINED ModuleLoader 形态，零构建零新依赖；宿主无 `settings.section` 插槽时软探测跳过，宿主侧技能注册不受影响。
- **校验扩展**：smoke 新增 optional 与目录一一对应、条目元数据齐备、core/optional 名称零交集断言（22 项）；新增 `pnpm selftest` 宿主侧 mock 全流程自测（注册数 / fence / 启停 / 持久化 / dispose，17 项）。

## 兼容性

- 1.0.x 用户升级后**默认行为完全不变**：31 项核心技能照常注册；optional 批零注册、零目录开销，设置页多出「可选技能」分区供按需启用。
- 新增 `webServer` 服务注入：宿主必须提供 `ctx.webServer.register`（QiLin 3.0.0+ / DSH 0.1.6+ 均满足）；无法注入时插件激活失败，属既有 bundle 契约语义。
- 引擎无 `settings.section` 插槽的旧宿主：分区不出现（软探测），不影响技能注册与 API。

## 安装

DSH：

```bash
dsh plugin --profile web add dsh-skills-bundle
```

麒麟（QiLin 3.0.2+）：

```bash
qilin plugin --profile qilin add dsh-skills-bundle
# 或 GitHub 直装
qilin plugin --profile qilin add github:kkutysllb/dsh-skills-bundle
```

装完进 设置 → 可选技能 开启需要的长尾技能。KCoder 桌面版随版本内置分发，无需安装。
