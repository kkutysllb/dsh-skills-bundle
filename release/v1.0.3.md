# dsh-skills-bundle 1.0.3

## 变更

- 双通道契约固化：`pnpm smoke`（prepack 硬拦）新增 `qilin.bundle.patch` 声明断言，与 `dsh.bundle.patch` 断言并列。此前 smoke 只校验 dsh 通道，若 qilin 键被误删，npm 发布不会被拦截，而 QiLin 插件管理器会直接报 `not-a-bundle` 拒装。
- 技能覆盖路径表述精确化：runtime skill（rank 250）可被项目级同名技能覆盖——dsh 侧路径为 `.dsh/skills`，QiLin 侧文件系统 provider 实际扫描 `.qilin/skills`（rank 100）与 `.agents/skills`（rank 200），`cordis.patch.yml` 与 README 注释已分别标注。
- 纯文档/校验面变更，`entry.js` 与 `cordis.patch.yml` 的行为零改动，装过 1.0.2 无需重装。

## 安装

DSH：

```bash
dsh plugin --profile web add dsh-skills-bundle
```

麒麟（QiLin 3.0.2+）：

```bash
qilin plugin --profile qilin add dsh-skills-bundle
# 或 GitHub 直装
qilin plugin --profile qilin add github:kkutysllb/dsh-skills-bundle
```

KCoder 桌面版随版本内置分发，无需安装。
