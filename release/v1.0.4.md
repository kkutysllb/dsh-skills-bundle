# dsh-skills-bundle 1.0.4

## 变更

- **移除 6 个非编码内置技能**（产品负责人 2026-10-05 拍板）：`image-generation`、`video-generation`、`music-generation`、`podcast-generation`、`comic`、`deep-research`。KCoder 是编码产品，上述技能与编码无关；注册面 37 → **31** 项（manifest 与目录均已同步，`comic` 内对 `image-generation` 脚本的悬空引用随两者一并消失）。
- **移除同步脚本的递归排除缺陷**（本次一并修）：`scripts/sync-to-dsh-plugins.mjs` 的排除集把 `scripts` 与 `release` 视为**任意深度**排除，于是各技能自带的 `skills/<name>/scripts/*.py`——媒体类技能的**实际执行体**——被静默剔除出镜像。本次删除的 4 个媒体技能正是唯一带 `scripts/` 的技能，故在 1.0.3 及以前，两个安装入口（独立仓 / dsh-plugins 子目录）与 KCoder 内置副本**都只有 SKILL.md**，SKILL.md 里的调用路径条条是死的。修复后排除规则只在仓库根生效。
- **新增分发载荷不变量断言**：`skills/` 下的文件一个都不允许被排除规则命中。此失效模式是静默且双侧一致的（镜像与对账共用同一份遍历，被吞的文件两边同时消失、`--check` 报「与真源一致」），故单列一条用**无排除遍历**做对照的断言，同步与对账时都会跑。

## 兼容性

- 删除的技能在 1.0.3 及以前**本就不具备可运行条件**（脚本从未随包分发），故对使用者无可感知的能力回退。
- KCoder 桌面版配套变更（同批）：移除「设置 → 技能 → 多媒体模型」分区与 `$DSH_HOME/media-models.env` 的引擎注入（该 env 的唯一消费者就是上述技能）。
- 装过 1.0.3 的用户经插件管理更新到 1.0.4 后，31 项技能照常注册；被删技能目录随物化整体重建消失。

## 安装

DSH：

```bash
dsh plugin --profile web add dsh-skills-bundle
```

麒麟（QiLin 3.0.2+）：

```bash
qilin plugin --profile qilin add dsh-skills-bundle
# 或 GitHub 直装
qilin plugin --profile qilin add github:kkutysllb/dsh-skills-bundle
```

KCoder 桌面版随版本内置分发，无需安装。
